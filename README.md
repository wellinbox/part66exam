# ✈️ PART-66 Aircraft Maintenance Exam

เว็บระบบข้อสอบสำหรับนักศึกษาวิชาช่างอากาศยาน (Aircraft Maintenance Engineering)  
ออกแบบสำหรับใช้ฝึกทำข้อสอบและทบทวนความรู้ตามแนวทาง **EASA Part-66 / CAAT**

ระบบถูกพัฒนาด้วย **HTML, CSS และ JavaScript** โดยเน้นการใช้งานที่ง่าย รองรับทั้งคอมพิวเตอร์ แท็บเล็ต และโทรศัพท์มือถือ

---

## 🎯 Project Overview

โปรเจกต์นี้จัดทำขึ้นเพื่อเป็นระบบสำหรับฝึกทำข้อสอบ Aircraft Maintenance โดยแบ่งเนื้อหาออกเป็น Module เพื่อให้ง่ายต่อการศึกษาและทบทวน

ผู้ใช้งานสามารถเลือก Module ที่ต้องการทำข้อสอบ จากนั้นระบบจะสุ่มคำถามและตัวเลือกเพื่อให้การทำข้อสอบแต่ละครั้งมีความหลากหลาย

หลังจากส่งคำตอบ ระบบจะแสดงคะแนนและช่วยให้ผู้เรียนสามารถตรวจสอบข้อที่ตอบผิดเพื่อกลับไปทบทวนได้

---

# ✈️ Main Features

### 📚 13 Aircraft Maintenance Modules

ระบบรองรับการแบ่งข้อสอบออกเป็น Module สำหรับการศึกษา Aircraft Maintenance

ตัวอย่าง Module:

- Module 01 — Mathematics
- Module 02 — Physics
- Module 03 — Electrical Fundamentals
- Module 04 — Electronic Fundamentals
- Module 05 — Digital Techniques / Electronic Instrument Systems
- Module 06 — Materials & Hardware
- Module 07 — Maintenance Practices
- Module 08 — Basic Aerodynamics
- Module 09 — Human Factors
- Module 10 — Aviation Legislation
- Module 11 — Aeroplane Aerodynamics, Structures & Systems
- Module 12 — Helicopter Aerodynamics, Structures & Systems
- Module 13 — Aircraft Aerodynamics & Systems

> หมายเหตุ: รายการ Module สามารถปรับเปลี่ยนตามโครงสร้างหลักสูตรและข้อมูลข้อสอบของผู้จัดทำ

# 📝 Exam System

ระบบข้อสอบถูกออกแบบให้มีรูปแบบการใช้งานคล้าย Online Quiz / Google Forms

### ระบบรองรับ

- สุ่มลำดับคำถาม
- สุ่มลำดับตัวเลือก
- ทำข้อสอบใหม่ได้
- คำถามแต่ละข้อมีคะแนน
- ตรวจคำตอบอัตโนมัติ
- คำนวณคะแนนเป็นเปอร์เซ็นต์
- แสดงจำนวนข้อที่ถูก
- แสดงจำนวนข้อที่ผิด
- แสดงผลคะแนนหลังส่งคำตอบ
- สามารถตรวจสอบข้อที่ตอบผิด
- แสดงเฉลย
- แสดงคำอธิบายคำตอบ
- รองรับการทบทวนข้อสอบ
